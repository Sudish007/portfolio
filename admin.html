Owner access

This is the site owner's content editor. It has no server access and stores nothing here: saving requires the owner's GitHub token, which never leaves their own browser. Without it, this page can't change anything on this site.

Owner setup: how to create the token (once, 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: portfolio-admin · Expiration: 1 year
  3. Repository access → Only select repositories → Sudish007/portfolio
  4. Permissions → Repository permissions → Contents: Read and write (everything else: No access)
  5. Generate, copy the github_pat_… value, paste it above, Unlock.

The token is stored only in this browser (localStorage) and sent only to api.github.com and this site's own /api endpoints, which verify it against GitHub on every save. It can at most edit files in the one selected repo. Revoke or rotate it anytime from GitHub settings.
