# sudish.dev identity

## Idea
The primary identity is the domain itself: **sudish.dev**. The compact mark is **s.** — the first letter of Sudish followed by the domain period. The period also reads as a code token and as completion. It is the only colour accent.

## Logo system
- `mark.svg`: compact mark for nav, profiles, app tiles and large icons.
- `favicon.svg`: optically enlarged compact mark for 16–32 px use.
- `logo-horizontal-dark.svg`: primary lockup on dark backgrounds.
- `logo-horizontal-light.svg`: primary lockup on light backgrounds.
- `mark-mono.svg`: one-colour production mark.
- PNG exports: 32, 180, 192 and 512 px.

## Colours
- Ink: `#101218`
- Paper: `#f5f5f2`
- Accent: `#06b6d4` (dark contexts and the non-text period) / `#0e7490` (light-context text; 4.9:1 on paper)
- Slate: `#687080`

## Usage
- Keep clear space around the mark equal to the diameter of the period.
- Minimum digital size: favicon variant at 16 px; standard mark at 24 px.
- Never add gradients, glow, drop shadows, outlines, rotations or extra code punctuation.
- Do not recolour the period independently from the approved accent.
- For one-colour reproduction, use `mark-mono.svg`.
